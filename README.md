# Личный сайт Алексея Цоя — инструкция с нуля

Это уже готовый сайт. Все коды находятся в этой папке — ничего копировать из интернета не нужно.

## Что здесь находится

Открой папку проекта в VS Code. Слева ты увидишь такие файлы:

```
go-tiktok-senior-it/
│  go.mod
│  main.go
│  README.md
└─ static/
   │  index.html
   │  style.css
   └  app.js
```

* `main.go` — сервер на Go. Он запускает сайт и передаёт сообщения из окна чата в Llama.
* `static/index.html` — текст сайта: имя, блоки, интересы и кнопки.
* `static/style.css` — внешний вид: тёмно-зелёные цвета, размеры и расположение.
* `static/app.js` — логика окна чата: отправляет сообщение на сервер и показывает ответ.
* `go.mod` — служебный файл Go, он сообщает, что это Go-проект.

## Шаг 1. Установи программы (делается один раз)

### Visual Studio Code

1. Открой сайт https://code.visualstudio.com/download.
2. Скачай **Windows User Installer**.
3. Запусти скачанный файл и нажимай `Next`, затем `Install`.

### Go

1. Открой https://go.dev/dl/.
2. Скачай файл для Windows с расширением `.msi` и пометкой `amd64` (для обычного 64-битного компьютера).
3. Открой файл и нажимай `Next` → `Install`.
4. Полностью закрой VS Code и открой его снова.

### Ollama (локальный искусственный интеллект)

1. Открой https://ollama.com/download/windows.
2. Скачай и установи Ollama.
3. После установки Ollama обычно запускается сама и появляется в области значков рядом с часами Windows.

## Шаг 2. Открой готовый проект

1. Открой VS Code.
2. В верхнем меню выбери `File` → `Open Folder...`.
3. Вставь этот путь и нажми `Select Folder`:

   ```text
   C:\Users\user\Documents\Codex\2026-07-29\go-tiktok-senior-it
   ```

4. Если VS Code спросит «Do you trust the authors?», нажми `Yes, I trust the authors`.

## Шаг 3. Установи расширение Go в VS Code

1. Слева нажми иконку из четырёх квадратиков — **Extensions**. Или нажми `Ctrl + Shift + X`.
2. В поиске напиши `Go`.
3. Выбери расширение **Go** от Google и нажми `Install`.

## Шаг 4. Открой терминал

Терминал — это окно внизу VS Code, куда вводятся команды.

1. Нажми на верхнее меню `Terminal` → `New Terminal`.
2. Внизу должна открыться строка с путём к папке проекта. В неё вставляй команды из следующих шагов.

Проверь, что Go установлен:

```powershell
go version
```

Правильный результат выглядит примерно так:

```text
go version go1.xx.x windows/amd64
```

## Шаг 5. Скачай модель Llama

Введи в терминале команду:

```powershell
ollama pull llama3.2
```

Она скачает модель на компьютер. Это может занять несколько минут — не закрывай терминал, пока скачивание не завершится.

Проверь, что модель установлена:

```powershell
ollama list
```

В списке должна быть строка с `llama3.2`.

## Шаг 6. Запусти сайт

В терминале VS Code напиши:

```powershell
go run .
```

Если всё в порядке, появится строка:

```text
Portfolio is running at http://localhost:8080
```

Теперь открой браузер (Chrome, Edge и т.д.) и введи адрес:

```text
http://localhost:8080
```

**Важно:** не открывай файл `index.html` двойным кликом и не используй адрес, который начинается с `file:///`. Так покажется только дизайн, но Go-сервер и AI-чат работать не будут. Нужен именно адрес `http://localhost:8080`.

## Как менять сайт

В VS Code нажми на файл слева, поменяй текст и сохрани через `Ctrl + S`.

* Поменять имя или рассказ о себе — `static/index.html`.
* Поменять цвета и дизайн — `static/style.css`.
* Поменять информацию, которую знает Llama — `main.go`, найди строку `const systemPrompt`.

После изменений в `index.html` или `style.css` просто нажми `F5` в браузере. После изменений в `main.go` останови сайт сочетанием `Ctrl + C` в терминале и снова выполни `go run .`.

## Если что-то не работает

### `go` is not recognized

Go не установлен или VS Code не был перезапущен после установки. Установи Go из шага 1 и открой VS Code заново.

### `ollama` is not recognized

Установи Ollama из шага 1 и перезапусти VS Code.

### Llama пишет, что не подключена

1. Проверь, что значок Ollama есть рядом с часами Windows.
2. Выполни `ollama list` — там должна быть `llama3.2`.
3. Если модели нет — введи `ollama pull llama3.2`.

### Порт 8080 уже занят

В `main.go` перед запуском можно поменять порт так:

```powershell
$env:PORT = "8081"
go run .
```

Тогда сайт будет по адресу `http://localhost:8081`.
